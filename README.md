# 🎬 Movie Dataset Analysis

## 📌 Project Overview

This project focuses on analyzing a **Movie Dataset** using Python.
The main goal is to explore the dataset, understand movie ratings, and calculate important statistical measures.

For this project, I used **Pandas, NumPy, and Statistics** to perform data analysis and extract useful insights from the movie data.

## 🛠️ Technologies & Libraries Used

* 🐍 **Python**
* 🐼 **Pandas** – Data loading, cleaning, and manipulation
* 🔢 **NumPy** – Numerical calculations and statistical operations
* 📊 **Statistics** – Mean, Median, Variance, Standard Deviation, Percentiles, etc.
* 📓 **Jupyter Notebook / Google Colab**

## 📂 Dataset

The dataset contains movie-related information such as:

* Movie Name
* Movie Rating
* Genre
* Release Year
* Other movie-related attributes

## 📊 Analysis Performed

The following statistical operations were performed on the movie ratings:

* Mean
* Median
* Minimum Rating
* Maximum Rating
* Variance
* Standard Deviation
* Percentiles
* Data distribution analysis

### Example:

```python
import numpy as np

print("Mean Rating:", np.mean(Rating))
print("Median Rating:", np.median(Rating))
print("Minimum Rating:", np.min(Rating))
print("Maximum Rating:", np.max(Rating))
print("Variance:", np.var(Rating))
print("Standard Deviation:", np.std(Rating))

print("25%:", np.percentile(Rating, 25))
print("50%:", np.percentile(Rating, 50))
print("75%:", np.percentile(Rating, 75))
```
